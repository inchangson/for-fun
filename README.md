# 비공개 자료 사이트

한국어 정적 문서 사이트. 제목·목차·본문·외부 출처 링크를 포함한 모든 문서 데이터는 암호화되어 있습니다. 공개 HTML/JS/CSS에는 공통 잠금 화면과 렌더러만 있습니다. 문서는 비밀번호를 입력한 탭의 메모리에서만 유지합니다.

## 실행과 빌드

```sh
npm ci
npm run dev
npm test
npm run build
npm run test:e2e
npm run preview -- --port 4173
```

배포 디렉터리는 `dist/`만 사용합니다. 저장소 루트를 웹 서버로 제공하지 마세요. 기존 Netlify 설정을 유지하며, 이 작업에서 외부 배포는 실행하지 않습니다. 상대 자산 경로와 불투명 ID 해시 라우트로 정적 하위 경로 배포를 지원합니다.

## 문서 편집

원문은 Git에서 제외된 `.private/details.json`, 비밀번호는 `.private/password.txt`에 있습니다. 기존 비밀번호를 유지합니다. 문서의 page ID는 임의 32자리 hex 값입니다. 원문은 UTF-8 JSON이며 구조는 `site/src/crypto.js`의 `validPrivateData`에서 검증합니다. 제목·목차·내용·출처 URL 등 문서에 관한 정보는 공개 소스나 테스트에 기입하지 않습니다.

```sh
npm run encrypt
npm run build
```

암호화는 Web Crypto PBKDF2-SHA-256 600,000회, 임의 16바이트 salt, AES-256-GCM, 매번 새로운 12바이트 IV를 사용합니다. 비밀번호 변경은 `npm run encrypt -- --prompt`의 숨김 입력으로 수행합니다. 비밀번호·키를 명령 인수나 `VITE_` 환경 변수에 넣지 마세요. Netlify는 비밀번호나 원문 없이 미리 생성한 암호문을 배포합니다.

기존 여행 원문과 암호문의 작업 전 사본은 로컬 `.private/archive/`에 보관합니다. 이 폴더와 원문은 절대 배포·커밋하지 않습니다. 이전 Git 이력이나 기존 배포를 지우는 작업은 포함하지 않습니다.

## 잠금 동작

글로벌 토글로 전체 문서를 열고 잠급니다. 내부 이동만 잠금 해제를 유지하며 OFF·새로고침·pagehide·BFCache 복원 시 잠깁니다. 대기 중 해제를 취소하면 뒤늦은 복호화 결과도 표시하지 않습니다. 오류·변조·잘못된 스키마는 닫힌 상태로 처리합니다.

문서 텍스트는 `textContent`로만 표시하고, HTTPS 링크만 해제 후 생성합니다. 잠그면 문서 DOM과 링크를 제거합니다. 문서 제목은 브라우저 제목에 넣지 않으며, 해시에는 불투명 ID만 사용합니다. 브라우저 저장소·분석 도구·외부 폰트·이미지 요청은 사용하지 않습니다. 열람·복사한 데이터의 회수나 물리적 메모리 삭제는 보장하지 않습니다.

## 검증

단위 테스트는 암호화·변조·스키마·URL·배포물 누출을 검사합니다. 빌드 때 로컬 원문이 있으면 암호문 일치 여부를 확인하고, 본문 문자열·비밀번호가 `dist/`에 없는지 검사합니다. 원문이 없는 CI 빌드는 구조적 검사만 수행합니다.

브라우저 테스트는 로컬 원문과 비밀번호를 읽되 출력하지 않습니다. 성공·실패·취소 경쟁 상태·페이지 이동·생명주기·저장소·모바일·하위 경로를 확인합니다. 기본 Chrome 경로는 macOS 기준이며 `CHROME_PATH`로 변경할 수 있습니다. 스크린샷·trace·동영상은 비공개 내용을 포함할 수 있으므로 자동 생성하지 않습니다.
