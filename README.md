# Hinge

회원 가입이나 서버 없이 브라우저 `localStorage`만 사용하는 영어 연습 정적 사이트입니다.

## 파일 구조

- `index.html`: 화면의 정적 템플릿과 접근성 구조
- `assets/content.js`: 활동별 학습 콘텐츠, 단어 설명, 용례 검토 출처
- `assets/styles.css`: 반응형 레이아웃과 시각 스타일
- `src/app.js`: 렌더링, 채점, 클립보드, 음성 재생, 로컬 저장 로직

콘텐츠를 늘릴 때는 `assets/content.js`의 `catalog`에 회차를 추가합니다. UI 로직과 콘텐츠 데이터가 분리되어 있으므로 템플릿을 수정할 필요가 없습니다.

## 로컬 실행

정적 파일 서버라면 무엇이든 사용할 수 있습니다.

```sh
python3 -m http.server 4173
```

그다음 `http://localhost:4173`을 엽니다. 배포 시에도 별도 빌드 과정이 필요하지 않습니다.

## 로컬 데이터

`hingeEnglishState.v1` 키 아래에 다음 데이터를 저장합니다.

- `progress`: `lvl-항목`별 현재 회차와 완료 회차
- `drafts`: 장문 작성 초안
- `answers`: 문장 조립, 빈칸, 독해, 받아쓰기 답안
- `words`: 사용자가 저장한 단어

데이터 관리 화면에서 항목별 진도와 단어 목록을 서로 독립적으로 초기화할 수 있습니다.
